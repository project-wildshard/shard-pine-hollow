# Retain the remaining image-mode payloads

After the image files were restored, a real native phone boot of Pine
revealed a missing original stone LOD1 GLB. A full census of every
explicit payload in both image-mode flows and both tiers, across all
28 frozen products, found nine model omissions: Pine eight, Driftwood
one. Add these existing authored files to the mount lists together.
No model or texture byte changes. Engine publication checks cover these
raw fallback payloads too; no rendering or probe changes are required.
