# OF23a: Pine's species as rows (opus-of23)

- `generators/hullSpecies.ts`: the native deer, elk, boar and bear and both
  thralls (`pine.boar.thrall`, `pine.elk.thrall`) as rows through the SDK's
  `speciesProgramToRows` and `hullCreature` looks (hull book coats, 256-texel
  maps, flaps, fur; the thralls' extras as `parts`), wired into the shard file
  with the kit harvest items. Rows only: the roster still stands the bodies.
- Every species file is a library root: Pine names some of the same bytes
  (its baked coats) as late files, and a late file must be a library root.
- Needs SDK 0.4.18 (sharddev a9b29a4a + 4e8b84e0) and an engine carrying
  0b7d50e9f (partial hunt motion) before it can land.
- Pins SDK 0.4.18 and engine 0.1.53 (opus-sdk-pine). Proven on the
  packed release/v0.1.53 (`b889e739`) and the 0.4.18 candidate packed
  from sharddev `8e02bb68`: build, `shard-format validate`, 43 vitest
  cases, typecheck, lint, the owned journey, package products and the
  grid re-entry and census tests. The lockfile follows once both are
  on npm.
