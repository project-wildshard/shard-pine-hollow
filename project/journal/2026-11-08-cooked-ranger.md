The actual CLI product cold-cooks in 68.82 seconds locally, with 259
server files and 49 client parts. The full 74.01-second case admits two
native worlds from only extracted, hash-verified server packs. The real
road/porch approach and interaction earn talked:ranger, distant input
stays refused, and five restored input ticks match the opaque control.
No event, flag, body or encoder is injected.

after its one source build; quick cases and all git hooks are unchanged.

local output is removed with its literal clone path after this result is
recorded. Cook roots and native worlds close in finally. Ranged ownership,
complete quests, client boot and rendering remain their separate rows.
