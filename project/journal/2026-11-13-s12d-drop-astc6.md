# 2026-11-13: Pine drops the phone rows the cook can make (S12d)

Meta SHARD-SIZE S12d. Engine's cook makes the phone's ASTC 6x6 file
from a phone row's KTX2 or GLB target (the box since `21959b0912`, the
app build since S12d's engine half). Of Pine's 83 hand-made overlay
rows, 30 have such a target in the baked `GPU_FILES.phone` (horizons,
sky, tree cards and impostors, hero props, NPCs, birds, weapons): their
files (7.8 MB) go, `astc6.generated.json` drops them, the fence reads
name the `/assets/gpu/` twins and the mounts now list those 20 targets
the table names but the mounts did not.

53 rows stay, because the cook has nothing to make them from:

- 18 `#layer` twins (the ground and bark layers): product blobs the
  ground program carries, at 1024.
- 35 rows with no phone row in the baked table (cabin props, prop
  recipes, building textures): the phone's only KTX2 is the hand-made
  file; the desktop reads the images.

Those need KTX2 masters first (meta SHARD-SIZE S12f). The hero is
restamped: only the phone's file encoding moved.
