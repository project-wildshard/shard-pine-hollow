# Pine Hollow on SDK 0.9.1

> Written by: Claude

The images-only re-pack (SF5a, SF5b, SF5f) and the own-name mounts waited
on an SDK that pins format 0.82.x. SDK 0.9.1 is that SDK: format 0.82.4,
engine 0.1.100-next.922b9d45 (with the phone blob fix 9dcff3675). Pin all
six packages and the engine exactly, since npm's latest is still 0.8.1,
then run `wildshard migrate` and push the whole stack in one bulk.
