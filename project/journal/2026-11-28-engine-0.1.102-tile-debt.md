# Pine on engine 0.1.102, tile debt cleared

> Written by: Claude (opus-ship2)

Pine's 80 tile-debt rows were an engine artifact: its pin (0.1.100-next.922b9d45) charged library files on every tile.
Engine e080b2018 charges them once per shard, and 0.1.102 carries it, so the pin moves to 0.1.102 (npm latest since
10:22 UTC on 11-28) and `lint/tile-bake-debt.json` keeps `"pine-hollow": {}`. `pnpm build:shards` prints 0 existing debt
metrics over 16 full 5x5 windows. Meta QA 11-26 row 76.

The debt file also names `open-plot-desert-ruin` twice; a JSON round-trip drops one copy, so Pine's entry was edited as
text.

The format pins move from 0.82.4 to 0.82.8 with it: engine 0.1.102 bundles shard-format 0.82.8, and two
`SpeciesRow` types from different format versions failed `pnpm typecheck` under exactOptionalPropertyTypes.
