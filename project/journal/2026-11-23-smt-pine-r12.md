# Pine Hollow r12 on the Track F toolchain

The r12 source includes the King ribcage socket fix in `a87b839`. It
uses SDK 0.4.27 with shard-format 0.71.0 and the exact v0.1.74 engine
prerelease. The CI21 source proof reads the same released engine commit
so it can open the product written by the new format.

The hosted grid re-entry proof on `55e85ad` rejected the kept row on
engine 0.1.65. The new pin moves the proof and retains the same grid
eviction, held items and quest progress assertions.

The CI21 witness keeps its Ledger revision field and supplies the
value from the reader’s normalized saveRevision. This keeps the same
checkpoint checks against the current reader.
